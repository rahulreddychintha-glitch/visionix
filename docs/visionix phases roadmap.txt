# Visionix — Official Development Roadmap

## Modified 18-Phase Implementation Roadmap

### 1. Project Vision

**Visionix** is a premium, full-stack, AI-powered career guidance platform designed to help students, graduates, job seekers, working professionals, career changers, and self-learners make informed career decisions and continuously develop toward their target careers.

The platform should provide personalized, reliable, scalable, and production-ready career guidance using real user data and real integrations rather than mock functionality.

### 2. Core Technology Stack

* **Frontend:** React + Vite
* **Backend:** Node.js + Express
* **Database:** MongoDB Atlas
* **Authentication:** JWT-based authentication
* **Styling:** Tailwind CSS / existing project styling system
* **Animations:** Framer Motion
* **AI:** Gemini / approved AI provider
* **Video Learning:** YouTube Data API
* **Charts & Progress Visualization:** Chart.js / Recharts where appropriate
* **Payments:** Razorpay for premium functionality
* **Deployment:** Vercel + Render
* **Docker:** Optional where required

---

# 3. Implementation Principles

These principles apply to every phase:

1. **Do not regenerate completed functionality.**
2. Always inspect the existing implementation before making changes.
3. Extend the existing architecture instead of creating duplicate systems.
4. Do not replace working functionality without a clear reason.
5. Keep modules modular, reusable, scalable, and production-ready.
6. Do not use fake/mock data where real functionality is required.
7. Preserve existing approved UI decisions unless a redesign is explicitly approved.
8. Verify functionality after implementation.
9. Run appropriate TypeScript/build/lint checks after major implementation work.
10. Do not move to the next phase until the current phase has been implemented, tested, verified, and explicitly approved.
11. Future phases must remain compatible with already completed phases.
12. API keys and secrets must remain server-side and must never be exposed to the client.

### Milestone Verification

Milestones should support:

* In Progress
* Completed & Verified
* Completed — Review Recommended
* Upcoming

Assessment results should be able to verify milestone completion in the future assessment system.

A failed assessment should **not block the user from continuing**. Instead, Visionix should recommend reviewing the relevant milestone material and allow the user to continue or retake the assessment later.

### Phase 10 Navigation Integration

The roadmap includes navigation points for future learning modules:

* **Take Assessment**
* **Learn from YouTube**

At this stage, these buttons should navigate to the existing **Module Under Development** experiences.

The actual Quiz & Assessment system and YouTube Learning system are **not part of Phase 10 implementation**.

# 5. Phase Completion Policy

A phase is considered **completed only when**:

1. Implementation is finished.
2. Existing functionality has not been unnecessarily broken.
3. Required functionality has been manually verified.
4. TypeScript/build checks pass where applicable.
5. Lint checks pass where applicable.
6. Major integration paths have been tested.
7. The user explicitly confirms the phase is complete.

Once confirmed, the phase becomes **locked** and should not be regenerated or reimplemented in later phases.
