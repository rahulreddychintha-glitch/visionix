Project Name:
Visionix

Visionix is a premium AI-powered Career Guidance Platform that helps users discover careers, learning paths, skills, colleges, universities, certifications, scholarships, internships, jobs, and career roadmaps using Artificial Intelligence.

The goal is to build one of the world's best AI career platforms.

Visionix is NOT limited to Computer Science.

It supports ALL academic backgrounds, professions, industries, certifications, vocational programs, and career paths worldwide.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

YouTube recommendations must use real YouTube API data when the YouTube Data API is configured.

The API key must remain server-side.

Frontend code must never expose the YouTube API key.

The secure backend endpoint is:

GET /api/personalization/youtube

If YOUTUBE_API_KEY is missing:

Return a successful empty response.

Example:

{
  "success": true,
  "message": "YouTube search disabled.",
  "data": []
}

If the YouTube API fails or returns no results:

Return an empty array.

Never return seeded or fabricated videos.

The frontend should display the existing neutral state:

"YouTube learning tutorials are currently unavailable."

Do not redesign the YouTube card to compensate for missing API data.
